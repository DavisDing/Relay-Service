## 实现位置

- `web/src/solar.ts`、`ui.tsx`：日出日落算法、定位与主题生命周期；无新增依赖。
- `web/src/ServiceDialogs.tsx`、`style.css`、`main.tsx`：预览交互、历史表格与表单尺寸。
- `web/src/api.ts`、`presentation.ts`：错误码、检查分类、历史消息中文展示。
- `server/internal/api/server.go`、`monitor/preview.go`：同步管理员预览与凭据/目标约束。
- `server/internal/monitor/details.go`、`checker.go`、`scheduler.go`、`types.go`：固定只读采集、受限字段投影、快照与状态机复用。
- `web/src/CheckDetails.tsx`：订阅/目录/公开状态证据与采集时间展示。

详情字段属于现有JSON记录的可选扩展，无SQL迁移、无删除或回填。旧记录继续读取。真实凭据不在本轮使用；测试为合成数据。

## 未完成验收与能力边界

- 浏览器定位通常需要HTTPS；普通NAS HTTP IP入口可能无法定位。拒绝定位时无法按实际当地日出日落计算，界面会明确说明。
- 本轮没有访问真实NAS/mihomo/中转站，也没有发布远程CI或镜像。真实版本、鉴权、网络与持久化仍须安装验收。
- mihomo订阅信息依赖provider及订阅响应头；MetaCubeXD网页与mihomo控制API应分别接入。未返回的流量/到期信息显示未提供，不冒充0额度或无限。
- 任意公开HTML状态页没有统一协议；当前只支持Statuspage标准JSON。自定义中转站需要其明确接口适配，不能宣称所有网站已支持。
- 模型目录只证明目录可读，Statuspage只证明服务商报告。逐模型实际可用性和失败率仍需日志/统计接口或另行授权有预算的推理探针，本轮没有实现或调用它们。
