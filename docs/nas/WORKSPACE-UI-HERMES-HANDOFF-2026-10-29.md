# 大模型与网络代理 UI 统一交接

本次按用户指定 apple-design 技能与 DESIGN 5.3 收敛两个新增工作区。数据接口、权限、采集任务和探针执行范围不变；没有新增依赖或存储迁移。

## 实现

- `web/src/Workspace.tsx`：公共页签、指标卡片与空态；复用现有 Button/Icon。
- `web/src/workspace.css`：统一面板/实例栏、48px次按钮、44px文字按钮及页签、搜索筛选、字体间距、状态、表格、分页、键盘焦点及辅助功能偏好。所有表格可键盘聚焦后横向滚动；数值/时间列标题与内容均居中。
- `models.css` / `network.css`：仅保留对应业务布局。模型窄屏保留目录、部署和调用状态；网络订阅窄屏单列。搜索框显式使用横向布局，防止继承全局label纵向规则；采集设置复选框保留可点击整行。
- 公共卡片与工作区复用圆角token；嵌套表格使用实色材料；深浅色沿用既有主题变量。

## 本次核查边界

- TypeScript检查与Vite生产构建通过；差异空白检查通过。
- 仅使用本机临时HTTP服务与明确标识的合成数据预览，未读取或写入真实NAS、mihomo或LiteLLM。
- 浏览器检查390px手机竖屏模型/订阅及展开详情、320px节点表格/采集设置、1280px桌面深色网络概览/模型渠道表及展开详情；所查页面未出现整页水平溢出。320px节点表仅在自身容器横向滚动；刷新按钮仍为44×44px圆形。页签测得44px，实例选择框48px；表格正文14px、表头12px，时间表头与值均居中。390px展开模型的目录、部署和历史调用字段均可见，内嵌表格为实色。
- 按用户此前安排未运行自动化测试。真实设备、实际服务数据、辅助功能媒体偏好、文字放大、完整页签及交互回归仍由Hermes验收；构建和合成预览不能代替这些验收。

## Hermes验收重点

1. 320/390/768/1280px及旋转、200%文字放大：长来源/模型/节点名、筛选、分页、长日志和空态不遮挡、不丢信息。
2. 两页各六页签及详情展开、订阅→所属节点、节点历史关闭、元数据导入、采集设置保存/重读与loading/禁用/错误反馈；仅使用获授权的测试环境。
3. 浅色、深色、减少透明度、高对比、减少动态分别检查；确认嵌套材料可读、状态有文字、焦点可见且不被裁切，搜索框仅显示外层焦点。
4. 键盘逐项导航、页签可达与横向滚动、详情展开、表格内横向滚动及原导航/对话框焦点恢复。
5. `web/` 的 `pnpm test` 与 `pnpm build`；构建不替代视觉回归。
