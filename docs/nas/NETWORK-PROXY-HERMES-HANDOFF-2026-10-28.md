开始日期：2026-10-28；实现收尾：2026-10-29（Asia/Shanghai）。授权：用户确认“可以，实施吧”，本轮仅实施网络代理。用户此前要求跳过测试、由Hermes测试，因此本轮**未执行测试、构建、浏览器交互验收、真实NAS认证联调或部署**。以下是代码交接，不是通过报告。此前UI修复和其他未提交工作保留，大模型工作区未进入本轮实现。

## 实际入口与接入

顶部/手机导航新增“网络代理”，服务总览mihomo详情提供进入链接。页面沿用Relay主题、卡片、表格和手机横向滚动；页签为概览、用量、订阅、节点、连接、日志。

1. 在服务总览添加或选择mihomo类型，填写核心API origin和secret作为检查凭据；私网地址继续需要显式允许私网。
2. 网络代理→概览→后台采集与日志保存，可另外填写MetaCubeXD控制服务origin（原面板的协议/主机/端口）及该服务的CONTROL_TOKEN。它与核心secret独立，不能将核心secret自动转发到面板域。控制接口未开放/无权限时，核心视图仍可使用，配置文件订阅来源显示受限。
3. profiles/provider可自动提供多订阅；不要求在浏览器原面板保持连接。若管理层暂不可用，可显式导入安全JSON元数据：最多100订阅/总5000节点，网页文件上限60KiB、API整个请求64KiB。不导入原始YAML、订阅URL或节点密码。
4. 日志默认仅实时短缓冲；管理员明确开启持久日志后默认24小时/20MiB，并有5000条额外上限。可配置1～168小时/1～100MiB，关闭不立即删除旧数据，到期回收。

## 已编码功能与边界

| 区域 | 代码行为 | 不能据此推断 |
|---|---|---|
| 概览 | 实例选择、速率、累计流量、活动连接数、内存（跳过流的首帧占位0）、内核版本、订阅/节点数量与证据状态、采集来源 | 全绿色不代表代理端到端可用；各源失败/过期单列 |
| 用量 | 核心累计值差分，1h/24h/7d图，计数器重置、样本与覆盖；查询完整窗口聚合至最多180点 | 不继承MetaCubeXD浏览器IndexedDB，不补算离线/首接入之前流量 |
| 连接分组 | 管理员按客户端/规则/完整代理链查看连续快照差分，小时聚合7d；API显示实际整小时覆盖起止 | 非完整账本，首见/断流/短连接可能缺失；三维度相同流量不可相加，更不能再加到核心总量 |
| 多订阅 | 核心providers与控制层local/remote profiles分别显示名称、额度/剩余/到期、激活标记、目录完整性；搜索和分页 | provider为空不代表没有订阅；不同来源不自动合并计费；0总额/缺字段不伪报健康 |
| 节点 | 核心节点及配置目录，所属订阅名/协议/已有延迟/检测时间；搜索、订阅/状态筛选、分页与详情 | 控制层配置激活不证明其与当前核心同一安装；同名同协议不借用健康，未关联目录保持未知 |
| 24h历史 | 后台积累与7d保留，UI以源checked_at落位、去重并展示96个15分钟桶、延迟散点和样本成功率 | 无新检测的时段保持灰色，不能以旧样本填满连续在线SLA；未激活订阅不会获得新延迟 |
| 连接 | 活动连接主机/IP、客户端、协议、规则、代理链、上传下载/速率/开始和持续时间，源提供时显示进程 | 默认不持久保存连接明细，采样可漏掉短连接；没有断开连接操作 |
| 日志 | 核心等级/接收时间/安全分类摘要，Relay采集异常与恢复事件；搜索/等级筛选、缓冲、持久开关及覆盖 | 原始访问日志正文、完整历史、可信节点关联尚未提供；无法安全结构化的正文不回显 |

配置YAML在后台内存用yaml.v3 v3.0.1（go.sum已有锁定）解析，仅提取顶层proxies名称/协议；1MiB响应、节点/深度/语法复杂度限制，alias/merge拒绝。proxy-providers引用显示覆盖不完整，**不会下载第三方订阅URL**。多订阅详情分批推进，单轮最多4个，超限和源失败写coverage。原始配置、节点连接秘密、上游错误体均不保存/返回。

后台同时最多32个mihomo实例，每实例共享traffic/memory/logs三路HTTP流、约2秒连接轮询、约60秒节点/版本读取；控制列表整轮完成后约5分钟刷新。网页读取共享缓存，概览/连接/日志约5秒，其余约15秒刷新。服务关闭/移除、配置代际或采集设置版本变化会取消旧worker；旧worker无法提交新版数据。

同一服务仅改名/间隔等且目标不变，采集偏好和内部历史epoch保留。kind/核心origin/控制origin变化开新历史epoch防混源；换核心目标还会暂停详情采集并清除目标相关控制配置与导入目录，需要管理员显式再开。暂停偏好不会因简单编辑或类型来回切换自动恢复。JSON新增network.*分桶，无SQL结构迁移；现有SQLite迁移复制通用记录，同样携带新增桶。旧epoch按原到期回收，不改写旧历史。
