## 交付范围

- 侧栏改为吸顶顶部导航，内容高 48px、边界 1px；现有监控页归组，管理员管理/诊断与设备只读权限保持原边界。
- 桌面可悬停展开或点击固定展开；菜单高度/位移过渡 280ms、内容淡入 200ms、遮罩 220ms。账户面板统一提供主题选择及退出登录。
- 页面切换入场 240ms、位移 6px，容器 key 仅跟随页面。刷新请求不更改该 key，此项由组件结构合同核对；当前浏览器观察接口不支持读取运行中的动画，未宣称完成逐帧或性能测量。
- 手机全屏菜单复用现有 `Modal`，不引入另一套焦点陷阱；导航支持 Escape、向下键、焦点恢复、跳过导航链接，隐藏展开面板具有 `inert`/`aria-hidden`。
- 对减少动态效果、减少透明度和高对比偏好提供 CSS 规则；未新增依赖、外部字体、图片或动画库。
- 本轮仅归组现有服务总览、告警、设备、设置、诊断五页。FR-W02 的完整八工作区及真实服务接入仍属后续范围，未用空页面补数。
