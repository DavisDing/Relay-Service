## 本版边界

NAS/Web、Mac、Android 同仓规划。统一运维 Web 可管理 Relay 自身配置；LiteLLM 原生 Key/模型/路由按已确认需求实施；其他外部服务只读接入。Ollama 允许无推理状态/目录/驻留总览，暂缓统计、模型管理和主动探针。镜像更新仅在安全只读证据充分时判断，无运行 digest 则显示未知并提供人工核对。

D-03 决定 workbuddy2api 独立只读能力/直连统计及非文本测试范围；D-04 决定正文内容/来源/接入与失败策略。技术版本、Android 分发/后台方案和真实环境验证由设计/实施补齐，不要求重新选择已确认产品方向。

线上写入、付费调用、基础设施变更和发布按 REQUIREMENT O 项明确范围。所有业务验收当前均未执行；本仓库只有文档检查入口。
